Plan:
My plan is to build a simple minimalist To-Do List web app that is fully responsive. I will be using HTML, CSS and JavaScript.
Core Feature is the task management: to be able to add new tasks, mark them as completed and to delete tasks one by one. I want to be able to control the input so that empty or short inputs are not allowed and the user will be notified in that case.
I want to learn how to use localStorage to store the data automatically so that it doesn't dissappear when browser is refreshed or restarted.

About the application:

Jas's To-Do List is a minimalist web application designed to help users organize daily tasks efficiently. Main features include adding tasks with input validation, marking items as completed with visual indicators, deleting individual tasks, and having a local data storage. No known issues, very basic functions.


Technologies: 

HTML - Used for the core structure.
CSS - styling and layout, visual error feedbacks
JavaScript - Makes the application interactive, event handling, input validation, DOM scripting
localStorage – Automatically saves task data directly in the browser so lists persist across page refreshes and sessions.


How to Use the Application:


Open the published application using the link.

Type your task into the input field.

Click the Add button to insert the task into the list, click an existing task to toggle it as completed, or click the cross (×) icon to remove it completely.

Refresh the page to check that your task data remains saved in the browser.

View all, active or completed tasks. 


Self-assessment: 

I would give myself an 8/10 for this assignment. I am quite a beginner so I had to rely on the tutorial a lot in the beginning. Besides that, I still think that using tutorial is a lot better way to understand the code step by step vs just having AI doing most of the work. The most challenging parts were CSS layout adjustments—specifically positioning the custom radio and check icons using ::before pseudo-elements so they didn't overlap the task text. I could develop the application further with more options like creating separate lists for e.g. Groceries, School etc.
I think that the task strengthened my skills and I got to try the learned things in a real task. In the future I think it is useful to know and understand the code but also to use AI/AI Agents so that is something I will want to dive deeper into in the future.
